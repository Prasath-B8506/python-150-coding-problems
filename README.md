# Python 150 Coding Problems

My Python coding practice and interview preparation journey through 150 programming problems.

This repository is based on a problem set covering:

- Operators
- Conditions
- Loops
- Number-based problems
- Pattern programming
- Arrays
- Strings
- Problem-solving and interview-style coding

## Objective

The goal of this repository is not just to solve 150 problems.

I am using these problems to improve:

- Python programming skills
- Logical thinking
- Problem-solving ability
- Coding speed
- Debugging skills
- Interview communication
- Ability to explain coding logic clearly

## Learning Approach

For every problem, I follow this process:

1. Understand the question
2. Identify the input
3. Identify the expected output
4. Understand the logic
5. Dry run with an example
6. Write Python code
7. Test the program
8. Check edge cases
9. Explain the solution
10. Commit the work to GitHub
